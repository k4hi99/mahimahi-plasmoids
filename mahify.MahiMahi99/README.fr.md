# MahiFy

[English](README.md) · **Français**

Le titre en cours sur Spotify, directement sur le bureau : pochette, titre, artiste, barre de progression et commandes de lecture.

![MahiFy](../screenshots/mahify.png)

## Utilisation

- Suit Spotify via MPRIS : l'application Spotify doit être lancée.

## Réglages

Onglets **Couleurs** et **Tailles** : le standard MahiTheme commun, avec ses 10 palettes, voir le [README général](../README.fr.md#lidée--un-standard-commun). Couleurs en plus : bouton pause, barre de progression. Tailles en plus : pochette, boutons.

## Installation

Depuis la racine du dépôt :

```bash
kpackagetool6 -t Plasma/Applet -i mahify.MahiMahi99
```
