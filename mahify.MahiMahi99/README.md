# MahiFy

**English** · [Français](README.fr.md)

The track playing on Spotify, right on your desktop: cover art, title, artist, progress bar and playback controls.

![MahiFy](../screenshots/mahify.png)

## Usage

- Follows Spotify through MPRIS: the Spotify app must be running.

## Settings

**Couleurs** (Colors) and **Tailles** (Sizes) tabs: the shared MahiTheme standard, 10 palettes included, see the [main README](../README.md#the-idea-one-shared-standard). Extra colors: pause button, progress bar. Extra sizes: cover art, buttons.

## Install

From the repository root:

```bash
kpackagetool6 -t Plasma/Applet -i mahify.MahiMahi99
```
